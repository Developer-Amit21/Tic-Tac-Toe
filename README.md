# ❌⭕ Tic Tac Toe Game

A simple 2-player Tic Tac Toe game built using HTML, CSS, and JavaScript.

## 🚀 Features

* Two-player gameplay
* Win & draw detection
* Interactive UI
* Reset functionality

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript

## ▶️ Run Locally

Open `index.html` in your browser.

* Add AI opponent
